# Guru Check

A checklist for judging a course, a Skool group, or a paid community before you pay.

The easy question is "is this person a scammer?" Funnels are built to survive that question. The video is real. The income screenshot might be real. Someone, somewhere, once made money the way the page describes. The money you send can still be gone, because you inspected the one kind of proof the page was designed to show you.

Guru Check asks a narrower question: **does the mechanism that made this person money still work when you run it yourself, and will they still be there when you need them?**

It also does the opposite job. A lot of quiet practitioners fail every red-flag list because those lists punish silence. This one has a way to notice them.

## What you get

- `SKILL.md`: the method, written so an agent can run it and a person can read it. It includes an evidence ladder for PR and podcast claims, a claim ledger, a guarantee audit, and a gate for using the word scammer in public.
- `references/signal-catalog.md`: the longer lists (guru fingerprints, community decay, Skool surface checks, creator-platform traps).

Private case files stay private. This repo is the method, not a dossier.

## Use it

Copy this folder into your agent skills directory, or paste `SKILL.md` into the chat when you are about to pay someone.

Give it a link: a Skool about page, a sales page, a founder profile. Ask it to check before you buy.

Read the opening table first. Then check the section called "What I could not verify." If that section is empty, the check is not finished.

## What it will not do

- It will not call a named person a fraud as a fact. It records signals, and it says when a point is still unchecked.
- It will not join, email, or buy for you.
- It is not legal advice and it is not a financial audit.
- A name on a roast list is not a verdict. Run the checklist, then quote the line you can actually open.
